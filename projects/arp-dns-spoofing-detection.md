# ARP and DNS Spoofing Detection with Attacker IP Capturing

## Overview

This academic cybersecurity project focused on detecting ARP and DNS spoofing attacks by inspecting network traffic and analyzing anomalous behavior. It also captured attacker IP metadata to help investigators follow up on suspicious activity.

The project was published in *Handbook of Algorithms in Advanced Artificial Intelligence* by Taylor & Francis in 2024.

## Problem

ARP and DNS spoofing can misdirect traffic by providing deceptive network-resolution information. The project explored how traffic inspection and anomaly analysis can help identify suspicious behavior and provide useful investigation context.

## Approach

- Inspected network traffic for patterns associated with ARP and DNS spoofing.
- Used anomaly-oriented analysis to identify potentially malicious resolution behavior.
- Captured attacker IP metadata to support investigation workflows.
- Tested in cybersecurity lab environments rather than against third-party systems.

## Technologies and Environment

- Python and Scapy
- Kali Linux, Ubuntu, and Windows
- VMware/VirtualBox for virtualized lab setup

## Relevance to Security Engineering

This project connects network protocol knowledge with practical detection and investigation. The same engineering habits—understanding expected behavior, inspecting evidence, preserving investigation context, and explaining why an event is suspicious—are useful in detection engineering and incident analysis.
